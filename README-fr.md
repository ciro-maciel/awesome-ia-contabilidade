## Étiquettes

Chaque élément indique ce qu'il est. Les étiquettes à côté aident à choisir : officiel quand cela vient de l'organisme qui définit la norme, open source quand le code est publié, gratuit ou payant selon le modèle d'utilisation, API et SDK selon la manière de l'intégrer. Les éléments avec l'étiquette "de l'auteur" sont réalisés par Ciro Cesar Maciel et suivent les mêmes règles que tous les autres.
