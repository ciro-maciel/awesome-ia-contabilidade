## AIのプライバシー

- [Google: atividade do Gemini](https://go.mymarketing.click/iacont-google-atividade-do-gemini) - Geminiのアクティビティ履歴をオフにする方法と、その影響。 `公式`
- [Microsoft: controles de privacidade do Copilot](https://go.mymarketing.click/iacont-microsoft-controles-de-privacidad) - Copilotのプライバシーと学習に関する設定の場所。 `公式`
- [OpenAI: controles de dados](https://go.mymarketing.click/iacont-openai-controles-de-dados) - ChatGPTの会話がモデルの学習に使われないようにする方法。 `公式`

## 公式情報源（確認用）

期限、表、義務について、定める機関から直接。

- [Agenda Tributária](https://go.mymarketing.click/iacont-agenda-tributaria) - Receita Federalが公表している、今月の期限一覧。 `公式` `無料`
- [Certificação digital no ITI](https://go.mymarketing.click/iacont-certificacao-digital-no-iti) - ITIによる電子証明書に関するよくある質問への回答。 `公式` `無料`
- [Lei Complementar 123/2006](https://go.mymarketing.click/iacont-lei-complementar-123-2006) - 零細企業法とSimples Nacional。 `公式` `無料`
- [Lei Complementar 214/2025](https://go.mymarketing.click/iacont-lei-complementar-214-2025) - 消費税改革に関する法律：IBS、CBS、選択的税。 `公式` `無料`
- [Manual de Orientação do eSocial](https://go.mymarketing.click/iacont-manual-de-orientacao-do-esocial) - eSocialの給与と労務イベントのマニュアル。 `公式` `無料`
- [MEI: perguntas frequentes](https://go.mymarketing.click/iacont-mei-perguntas-frequentes) - 個人事業主（MEI）に関する公式の回答。 `公式` `無料`
- [Procuração eletrônica no e-CAC](https://go.mymarketing.click/iacont-procuracao-eletronica-no-e-cac) - 顧客が電子証明書を渡さずに事務所へ委任する方法。 `公式` `無料`
- [Tabelas do Imposto de Renda 2026](https://go.mymarketing.click/iacont-tabelas-do-imposto-de-renda-2026) - Receita Federalによるその年のIRPF税率表。 `公式` `無料`

## タグ

各項目には何であるかが書かれています。横のタグは選ぶ際の目安です。公式は標準を定める側から提供されるもの、オープンソースはコードが公開されているもの、無料または有料は利用モデルによるもの、APIとSDKは組み込み方法を示します。「作者作成」タグの項目はCiro Cesar Macielが作成したもので、他の項目と同じルールに従います。
